**Pre-release.** The fourth beta of 1.5.1. It fixes reading progress in the desktop app and adds a default reading theme. Everything from the earlier betas is here too: the text book rework, Kindle formats and import, the dictionary, font settings, Android's update check, in-app updates for Windows installs, and the desktop book layout from [beta.3](https://git.jombo.uk/Jombo/rekindle/releases/tag/v1.5.1-beta.3).

## New

- **Reading theme in Settings** (desktop and Android). Choose the theme books open in: Match app, which follows the app's light or dark theme, or Light, Dark or Sepia. The palette button in a book still changes it for that visit.

## Fixes

- **Desktop: your place in a book sticks.** Closing a book and opening it again soon after could put you back where that visit started, and then save that over your newer progress. Progress is now saved as the book closes.
- Desktop: comics now save their page as they close too, rather than up to three seconds earlier.

## Upgrading

- **Desktop:** turn on **Receive pre-releases** in Settings → Updates, then **Check for updates**. On Windows, installs from the installer still on 1.5.0 or beta.1 need this version installed by hand once, from the download below.
- **Server:** no changes since beta.1. To move from 1.5.0, stop it, run `Rekindle.Server --dev-update`, start it, and back up `data/` first if you might go back to 1.5.0. Update the server before the clients: older servers can't stream books.
- **Android:** use Settings → Updates → **Check for updates** with **Include pre-releases** on, or install the APK below.

Every download except the Android APK has a `.sha256` next to it.
