**Pre-release.** The eighth beta of 1.5.1, including everything from earlier betas.

## New

- **Scheduled library scans:** admins can set a scan interval for each library in Admin Panel → Scans on desktop and Android.
- **Mark as read:** mark archives or whole folders as read without changing their saved reading position. Remove the mark whenever you want.
- **Ignore archive tracking:** exclude archives or folders from series progress, completion and new counts while keeping their individual reading progress. Use the desktop right-click or Android long-press menu to track them again.
- **Show file extensions:** an optional setting under Appearance on desktop and Android, off by default.

## Changes

- **Desktop page turns curl like paper**, with a curved fold, shading and a soft shadow in single-page and two-page book layouts.

## Upgrading

- Update the server before the clients to use scheduled scans, read marks and tracking exclusions. The server applies the new database migrations on startup.
- **Desktop:** enable **Receive pre-releases**, then use Settings → Updates → **Check for updates**.
- **Android:** use Settings → Updates → **Check for updates** with pre-releases enabled, or install the APK.

Every download except the Android APK has a `.sha256` next to it.
