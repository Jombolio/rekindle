**Pre-release.** The third beta of 1.5.0. Please report anything odd before the stable release.

## Fixes

- **Release notes in the desktop's update dialog are formatted.** They showed as raw Markdown (`##`, `**`); headings, lists, bold, code and links now display properly, and links open in your browser. Because the dialog belongs to the version you have installed, you'll see this from the update after this one.

## Upgrading

- **Server on 1.5.0-beta.1 or beta.2:** stop it, run `Rekindle.Server --dev-update`, start it. Your `appsettings.json`, `data/` folder and anything else you keep next to the server are left untouched.
- **Server on 1.4.x:** install by hand once (stop, unzip over the install folder with `unzip -o RekindleServer-linux-x64.zip -x appsettings.json`, start); from then on use `--dev-update`.
- **Desktop on a 1.5.0 beta** with **Receive pre-releases** on: Settings → Check for updates. Your settings, servers and downloads are kept.
- **Android:** install the APK below over the beta; your app data is kept.
- **Flatpak:** install `RekindleClient-linux-x86_64.flatpak` from this release.

See 1.5.0-beta.1 and beta.2 for everything else that's new in 1.5.0.
