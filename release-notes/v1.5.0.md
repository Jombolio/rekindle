Rekindle 1.5.0 shows how far you've read at a glance, flags new chapters, and keeps itself up to date.

## New

- **Reading progress on covers** (desktop and Android). A ring in the bottom-left corner of each cover fills as you read and turns into a green check when you finish. Series show their progress across every chapter, and progress from your other devices shows too.
- **"N NEW" badge on series** with chapters added since you last read them. Chapter lists mark new chapters, and subfolders show their progress and new-chapter counts.
- **The desktop app updates itself.** A few seconds after it starts (at most once a day) it checks for a new version and asks: **Update now**, **Later** or **Skip this version**. "Update now" downloads it, verifies it, installs it and restarts Rekindle.
  - Works for the Windows installer, the Windows and Linux portable zips, and the AppImage.
  - Flatpak can't replace itself: Rekindle downloads the new bundle and shows the command that installs it. AUR and other system installs update through your package manager.
  - Settings → Updates: turn the automatic check off, or turn on **Receive pre-releases** to try betas.
  - Release notes in the update dialog are shown formatted.
- **The server updates itself.** Stop it, run `Rekindle.Server --update`, start it. Your `appsettings.json`, `data/` folder and anything else you keep next to the server are left untouched, and every download is checked against a published SHA-256. `--check-update` shows what's available; `--dev-update` includes pre-releases. See [Updating](https://git.jombo.uk/Jombo/rekindle/wiki/Installing-the-Server#updating).
- **Updates come from git.jombo.uk**, falling back to GitHub when it can't be reached.
- **A Flatpak bundle in every release**, installed with `flatpak install RekindleClient-linux-x86_64.flatpak`.

## Fixes

- Text PDFs rendered with a black background; pages and covers are now white. Pages already cached keep the black background until they're evicted or the page cache is cleared.
- Updated ImageSharp to 3.2.0, fixing two security advisories in image decoding (GHSA-gwg2-r3hj-4w44, GHSA-wmxv-xphr-5c9g).

## Upgrading from 1.4.x

- **Server:** this is the first version that can update itself, so install it by hand once: stop the server, unzip the new release over your install folder **keeping your config** (`unzip -o RekindleServer-linux-x64.zip -x appsettings.json`), and start it. From then on, `Rekindle.Server --update` does it for you.
- **Desktop:** 1.4.x will offer this update (Settings → Check for updates). From 1.5.0 on, Rekindle updates itself.
- **Android:** F-Droid offers the update as usual, or install the APK below.
- **Coming from a 1.5.0 beta:** the server's `--update` and the desktop's automatic check both pick this release up.

Every download has a `.sha256` next to it.
