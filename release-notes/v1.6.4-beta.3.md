**Pre-release.** The third beta of 1.6.4. It fixes a crash in beta.2 on Android, and includes everything from earlier betas.

## Fixes

- **Books open again (Android):** in beta.2, opening any book froze the app and then closed it. The new read-aloud code split chapters into sentences using a pattern Android doesn't support, so every chapter failed to load. That's fixed, and if splitting a chapter into sentences ever fails again, the chapter now opens anyway, without read aloud highlighting.

## Still new in this beta (Android)

beta.2's read aloud is otherwise unchanged and still untested on many phones: the speaker button in a book's top bar, **Read aloud** on selected text, controls in a notification and on the lock screen with the screen off, and voice and speed under **Read aloud** in Settings → Books. See the [beta.2 notes](https://github.com/Jombolio/rekindle/releases/tag/v1.6.4-beta.2) for what to look out for.

## Upgrading

- **Android:** install the APK below. If you installed beta.2, update to this one.
- **Desktop and server:** no changes since beta.1 beyond the version number.

Every download except the Android APK has a `.sha256` next to it.
