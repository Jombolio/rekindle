**Pre-release.** The second beta of 1.5.0. Please report anything odd before the stable release.

## New since beta.1

- **Updates fall back to GitHub.** The server's `--update`, `--dev-update` and `--check-update`, and the desktop's update check, still use git.jombo.uk first. If it can't be reached they use the same releases on GitHub, and say so. On the server, `Rekindle.UpdateFallbackSource` sets the fallback; `""` turns it off.
- **A Flatpak in every release:** `RekindleClient-linux-x86_64.flatpak`, installed with `flatpak install RekindleClient-linux-x86_64.flatpak`. It doesn't update itself; install the newer file from each release.

## Fixes

- With **Receive pre-releases** off, the desktop said "No published release was found" when git.jombo.uk had only pre-releases. It now says you're up to date.

## Upgrading

- **Server on 1.5.0-beta.1:** stop it, run `Rekindle.Server --dev-update`, start it. Your `appsettings.json`, `data/` folder and anything else you keep next to the server are left untouched. There's nothing to add to your config: the GitHub fallback is on by default.
- **Server on 1.4.x:** install by hand once (stop, unzip over the install folder keeping `appsettings.json` and `data/`, start); from then on use `--dev-update`.
- **Desktop on 1.5.0-beta.1** with **Receive pre-releases** on: Settings → Check for updates. Your settings, servers and downloads are kept.
- **Android:** install the APK below over the beta; your app data is kept.

See 1.5.0-beta.1 for everything else that's new in 1.5.0.
