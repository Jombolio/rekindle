**Pre-release.** The thirteenth beta of 1.5.1, including everything from earlier betas.

## Fixes

- **No more black screen after resizing the window (desktop):** maximising the window, or restoring it, could leave the comic reader black until the page was turned. It happened when the window grew while you were near the end of a book, or when it passed through no size at all on the way, as maximising and restoring can on Windows. The page you're reading now stays on screen through any resize, in single-page and double-page reading.

## Upgrading

- **Desktop:** enable **Receive pre-releases**, then use Settings → Updates → **Check for updates**.
- **Android:** no changes since beta.12 beyond the version number.
- **Server:** no functional changes since beta.8. If upgrading from an earlier beta, update the server before the clients to use scheduled scans, read marks and tracking exclusions.

Every download except the Android APK has a `.sha256` next to it.
