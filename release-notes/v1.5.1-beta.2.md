**Pre-release.** The second beta of 1.5.1. It fixes in-app updates for Windows installs. Everything from [beta.1](https://git.jombo.uk/Jombo/rekindle/releases/tag/v1.5.1-beta.1) is here too: the text book rework, Kindle formats and import, the dictionary, font settings and Android's update check.

## Fixes

- **Desktop (Windows): in-app updates work for installer installs.** Copies installed with the installer, in Program Files, said "This is a development build" and offered no update unless Rekindle was run as administrator. They now offer **Update now**, which runs the installer and asks for admin rights as usual.
- Desktop (Windows): a portable copy in a folder you can't write to now says that's why it can't update itself.

## Upgrading

- **Desktop on Windows, installed with the installer:** install this version by hand once, from the download below. Earlier versions can't offer it. From this version on, updates install from inside Rekindle.
- **Desktop, other installs:** turn on **Receive pre-releases** in Settings → Updates, then **Check for updates**.
- **Server:** no changes since beta.1. To move from 1.5.0, stop it, run `Rekindle.Server --dev-update`, start it, and back up `data/` first if you might go back to 1.5.0. Update the server before the clients: older servers can't stream books.
- **Android:** no changes since beta.1. On beta.1, use Settings → Updates → **Check for updates** with **Include pre-releases** on, or install the APK below.

Every download except the Android APK has a `.sha256` next to it.
