**Pre-release.** The first beta of 1.6.4, for the desktop client's read aloud.

## New

- **Read aloud from here (desktop):** right-click a word in a book, or select some text and right-click it, then choose **Read aloud from here**. Reading starts at that sentence, or jumps there if you're already listening. Works in the page, spread and scroll layouts.

## Fixes

- **No more false "Download the voice" message (desktop):** pressing play in a book soon after starting Rekindle could say the voice wasn't downloaded when it was, until you pressed play again. Rekindle now finishes checking for the voice first. The voice picker in Reading options no longer shows the download prompt while it checks, either.

## Upgrading

- **Desktop:** enable **Receive pre-releases**, then use Settings → Updates → **Check for updates**.
- **Server and Android:** no changes since 1.6.3 beyond the version number.

Every download except the Android APK has a `.sha256` next to it.
