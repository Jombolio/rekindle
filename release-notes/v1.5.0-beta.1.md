**Pre-release.** A beta of 1.5.0 for testing. Please report anything odd before the stable release.

## New

- **Reading progress on covers** (desktop and Android). A ring in the corner of each cover shows how far you've read, and fills green with a check when you finish. A series shows its overall progress across all chapters, and progress from your other devices now shows too.
- **"N NEW" badge on series** with chapters added since you last read them. Chapter lists mark new chapters, and subfolders show their progress and new-chapter counts.
- **Server self-update.** Stop the server, run `Rekindle.Server --update` (newest stable release) or `--dev-update` (including pre-releases like this one), then start it again. Your `appsettings.json`, `data/` folder and any other files you keep next to the server are left alone, and every download is checked against a published SHA-256. `--check-update` shows what's available without installing anything. See [Updating](https://git.jombo.uk/Jombo/rekindle/wiki/Installing-the-Server#updating).
- **Desktop updates now come from Gitea** (git.jombo.uk), with a new **Receive pre-releases** switch in Settings, off by default.

## Fixes

- Text PDFs rendered with a black background; pages and covers are now white. Pages already cached keep the black background until they're evicted or the page cache is cleared.
- Updated ImageSharp to 3.2.0, fixing two security advisories in image decoding (GHSA-gwg2-r3hj-4w44, GHSA-wmxv-xphr-5c9g).

## Upgrading

- **Server:** this is the first version with `--update`, so install this one by hand: stop the server, unzip the new release over your existing folder (keeping your `appsettings.json` and `data/`), and start it. From here on, `--update` and `--dev-update` do it for you.
- **Desktop 1.4.1 and older** look for updates on GitHub and only see stable releases, so they won't offer this beta. Install it manually; from 1.5.0-beta.1 on, the app checks Gitea and can offer betas.
- **Android:** install the APK below; the F-Droid repository stays on stable releases.
