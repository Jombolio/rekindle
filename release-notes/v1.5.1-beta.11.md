**Pre-release.** The eleventh beta of 1.5.1, including everything from earlier betas.

## Fixes

- **Double-page turns use the centre as a spine:** a spread no longer swings away as one sheet. The half-page on the side you are turning from curls over the middle, carrying the next slide's facing page on its back, while the other half stays down until the sheet lands on it and the next slide's far page shows beyond the sheet's edge. This is the same turn the book reader does in a spread, and it is mirrored for right-to-left reading. On both desktop and Android.
- **The turning half is the printed page, not the window:** the letterbox beside a spread is no longer rolled up with the paper, which had been darkening the middle of the turn.

## Upgrading

- **Desktop:** enable **Receive pre-releases**, then use Settings → Updates → **Check for updates**.
- **Android:** use Settings → Updates → **Check for updates** with pre-releases enabled, or install the APK.
- **Server:** no functional changes since beta.8. If upgrading from an earlier beta, update the server before the clients to use scheduled scans, read marks and tracking exclusions.

Every download except the Android APK has a `.sha256` next to it.
