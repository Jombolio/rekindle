**Pre-release.** The third beta of 1.5.1. It makes text books readable in the desktop app. Everything from [beta.1](https://git.jombo.uk/Jombo/rekindle/releases/tag/v1.5.1-beta.1) and [beta.2](https://git.jombo.uk/Jombo/rekindle/releases/tag/v1.5.1-beta.2) is here too: the text book rework, Kindle formats and import, the dictionary, font settings, Android's update check, and in-app updates for Windows installs.

## Fixes

- **Desktop: books are laid out for reading.** Text sits in a centred column instead of running the full width of the window, and the column grows and shrinks with the text size.
- **Desktop: paragraphs are indented as the book intends.** Books that separate paragraphs with an indent, not a gap, no longer run their paragraphs together.
- Desktop: links in books, such as the contents page, are shown in the text colour instead of pale purple, without an underline unless the book asks for one.
- Desktop: the reader's top and bottom bars are solid, so text no longer shows through them.

## Upgrading

- **Desktop:** turn on **Receive pre-releases** in Settings → Updates, then **Check for updates**. On Windows, installs from the installer that are still on 1.5.0 or beta.1 need this version installed by hand once, from the download below.
- **Server:** no changes since beta.1. To move from 1.5.0, stop it, run `Rekindle.Server --dev-update`, start it, and back up `data/` first if you might go back to 1.5.0. Update the server before the clients: older servers can't stream books.
- **Android:** no changes since beta.1. Use Settings → Updates → **Check for updates** with **Include pre-releases** on, or install the APK below.

Every download except the Android APK has a `.sha256` next to it.
