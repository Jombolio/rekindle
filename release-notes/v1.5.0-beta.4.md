**Pre-release.** The fourth beta of 1.5.0. Please report anything odd before the stable release.

## New

- **The desktop app updates itself.** A few seconds after it starts (at most once a day) it checks for a new version and asks: **Update now**, **Later** or **Skip this version**. "Update now" downloads the update, checks it, installs it and restarts Rekindle; no trip to a website.
  - Works for the Windows installer, the Windows and Linux portable zips, and the AppImage.
  - Flatpak can't replace itself: Rekindle downloads the new bundle and shows the command that installs it.
  - AUR and other system installs are updated by your package manager.
  - Settings → Updates has a switch to turn the automatic check off; **Check for updates** still works any time.
  - Your settings, servers, downloads and reading progress are kept.
- **The reading-progress ring moved to the bottom-left of covers**, replacing the "Series" badge.

## Upgrading

- **Desktop:** install this version by hand once (from the download below, or Settings → Check for updates on beta.3 with **Receive pre-releases** on). It's the first with in-app updates, so from the next release on it updates itself.
- **Server on a 1.5.0 beta:** stop it, run `Rekindle.Server --dev-update`, start it. Your `appsettings.json`, `data/` folder and other files are left untouched.
- **Server on 1.4.x:** install by hand once (stop, `unzip -o RekindleServer-linux-x64.zip -x appsettings.json`, start); from then on use `--dev-update`.
- **Android:** install the APK below over the beta; your app data is kept.

Every download now has a `.sha256` next to it.
