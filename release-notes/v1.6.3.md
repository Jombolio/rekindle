Rekindle 1.6.3 makes sure new settings reach your server's `appsettings.json`, however you updated.

## Fixes

- **New settings now appear in your `appsettings.json`** (server). 1.6.2 added `Rekindle:Contacts` and `Rekindle:LandingTheme`, but updating to it with `--update` didn't write them into your file: the update is run by the version you already have, and versions before 1.6.2 keep `appsettings.json` exactly as it is. The server now adds any settings missing from your file each time it starts, with their defaults, and logs which ones it added. Every value you set stays as it is. This works whichever way you update: `--update` from any version, unzipping a release, or a package. A file with comments or trailing commas is left alone, and if the server can't write to its folder it leaves the file and says so in the log. Missing settings use their defaults either way.

To set the landing page theme or contact links after updating, look for `LandingTheme` and `Contacts` under `Rekindle` in `appsettings.json`. See [Configuration](https://github.com/Jombolio/rekindle/wiki/Configuration#landing-page-theme) on the wiki.

## Upgrading

- **Server:** stop it, run `Rekindle.Server --update`, and start it again. The new settings appear in `appsettings.json` on that first start.
- **Desktop and Android:** no changes since 1.6.2 beyond the version number. Desktop offers the update when it starts; F-Droid offers it as usual, or install the APK below.

Every download except the Android APK has a `.sha256` next to it.
