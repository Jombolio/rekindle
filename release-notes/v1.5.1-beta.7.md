**Pre-release.** The seventh beta of 1.5.1. Everything from the earlier betas is here too.

## New

- **Two pages reads like a book** (desktop and Android). Each chapter opens on a right-hand page, then pairs 2–3, 4–5 and so on.
- **Desktop: pages turn like paper.** In a spread, the right-hand page folds over the spine onto the left; a single page lifts away from its edge. Turning into another chapter turns the same way. Turn off **Page-turn animation** in the Aa panel for pages that change at once.
- **Desktop: Escape goes back,** from any screen, all the way to your libraries. Dialogs, menus and pop-ups close first.
- **Android: the version is shown** beside "Rekindle" on the main screen.

## Changes

- **Android: pre-releases take three taps to turn on.** They aren't recommended on Android, since going back to a stable release means uninstalling first. Tap **Include pre-releases** three times in quick succession; one tap turns it off.

## Upgrading

- **Desktop:** with **Receive pre-releases** on, use Settings → Updates → **Check for updates**.
- **Server:** no changes since beta.1. Update the server before the clients if you're coming from 1.5.0.
- **Android:** use Settings → Updates → **Check for updates**, or install the APK below.

Every download except the Android APK has a `.sha256` next to it.
