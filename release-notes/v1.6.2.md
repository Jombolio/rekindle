Rekindle 1.6.2 gives the server a landing page, and keeps your settings up to date when the server updates itself.

## New

- **A landing page for your server** (server). Open the server's address in a web browser, such as `http://192.168.1.10:8080` or `https://rekindle.example.com`, and you now see a page that explains what Rekindle is, links to the desktop and Android apps (Gitea and GitHub releases, and the F-Droid repository), and shows the server's address with a button to copy it into the app. Send it to the people you share your server with. It works offline on a LAN, loads nothing from other sites, and reads well on a phone. The API and the apps are unaffected.
- **Contact links on the landing page** (server). List ways to reach you, such as Discord, email, Matrix, Mastodon or a website, under `Rekindle:Contacts` in `appsettings.json`, and the page shows them under **Contact the administrator**. With none set, the section isn't shown. Only `http`, `https` and `mailto` links are shown.
- **Landing page theme** (server). The page follows each visitor's light or dark setting. Set `Rekindle:LandingTheme` to `Dark` or `Light` to always use one.

Both settings apply as soon as you save `appsettings.json`, without a restart. See [Configuration](https://github.com/Jombolio/rekindle/wiki/Configuration#contact-links-on-the-landing-page) on the wiki.

## Changes

- **`--update` brings your `appsettings.json` up to date** (server). Every value you set is kept, and settings added by the new release are written into your file with their defaults and listed when the update finishes, so new options are easy to find. Updating from 1.6.1 adds `Rekindle:Contacts` and `Rekindle:LandingTheme`. A file with comments or trailing commas is left exactly as it is. `appsettings.*.json` files are never changed.

## Upgrading

- **Server:** stop it, run `Rekindle.Server --update`, and start it again. If you update by unzipping the release instead, keep your `appsettings.json`; the new settings use their defaults until you add them.
- **Desktop and Android:** no changes since 1.6.1 beyond the version number. Desktop offers the update when it starts; F-Droid offers it as usual, or install the APK below.

Every download except the Android APK has a `.sha256` next to it.
