**Pre-release.** The ninth beta of 1.5.1, including everything from earlier betas.

## New

- **Settings categories on desktop and Android:** Settings now opens a landing page with separate pages for Appearance, Reader, Books, Downloads and Updates, plus platform-specific categories.
- **Book-style comic and manga page turns:** paged readers now offer hinged page turns for swipes and button navigation, including right-to-left reading. Enabled by default; turn off **Comic and manga page turns** under Settings → Reader to use sliding pages.

## Fixes

- **Desktop book animation:** fixed an empty first frame that flashed the next page, and made the curl settle flat without an abrupt shading change.
- **Page-turn input:** prevent repeated navigation inputs from interrupting an ongoing comic page turn.

## Upgrading

- **Desktop:** enable **Receive pre-releases**, then use Settings → Updates → **Check for updates**.
- **Android:** use Settings → Updates → **Check for updates** with pre-releases enabled, or install the APK.
- **Server:** no functional changes since beta.8. If upgrading from an earlier beta, update the server before the clients to use scheduled scans, read marks and tracking exclusions.

Every download except the Android APK has a `.sha256` next to it.
